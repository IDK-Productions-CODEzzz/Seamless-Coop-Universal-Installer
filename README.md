# Seamless Coop Universal Installer
The update to the [Elden-Ring-Seamless-Co-op-Installer](https://github.com/IDK-Productions-CODEzzz/Elden-Ring-Seamless-Co-op-Installer) project; this Windows BAT file quickly and easily installs or updates any of the Seamless Coop mods while preserving any pre-existing settings files.

# How to Use
1. Download the [Install-SeamlessCoop-Mod.bat](https://github.com/IDK-Productions-CODEzzz/Seamless-Coop-Universal-Installer/blob/main/Install-SeamlessCoop-Mod.bat) file. Pending release.
2. Download the Seamless Coop mod of choice from [Nexus Mods](https://www.nexusmods.com/profile/Yui/mods).
3. Make sure both files are in `Downloads`. If you decide to move them, move them together. Run the `Install-SeamlessCoop-Mod.bat` file.
4. Follow along with the prompts in the opened Command Prompt window.

As a bonus feature, this BAT file can download the Seamless Coop mods for [DARK SOULS™ II: Scholar of the First Sin](https://store.steampowered.com/app/335300/DARK_SOULS_II_Scholar_of_the_First_Sin/) and [ELDEN RING](https://store.steampowered.com/app/1245620/ELDEN_RING/) since [Yui](https://github.com/yuiamoroll) publishes releases for those two titles on her GitHub.
